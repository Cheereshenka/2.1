# Лабораторная работа №1 — оборудование и ход работы

## Аппаратная конфигурация

- Intel Core i7-12650H, 2,30 ГГц
- ОЗУ 16 ГБ
- Windows 10

## Что делает программа

Это учебный игровой автомат «Три мешочка». Программа создаёт виртуального игрока, выдаёт ему три монеты и позволяет проводить раунды. В каждом раунде одна монета становится ставкой, после чего пользователь выбирает один из трёх мешочков.

Результат выбирается случайно на основании выбранной стратегии. Далее результат передаётся по цепочке обработчиков. В зависимости от результата ставка либо теряется, либо удваивается, либо игрок получает бесплатный повторный выбор.

## Что демонстрируется

Главное демонстрируемое решение — паттерн Chain of Responsibility. Обработчики разделяют ответственность: один отвечает за проигрыш, второй за выигрыш, третий за второй шанс. Игровое состояние и кошелёк при этом находятся в отдельных классах.

## Сценарий демонстрации

1. Создать новую игру.
2. Показать баланс 3 монеты.
3. Нажать «Играть · 1 монета».
4. Выбрать мешочек.
5. Показать изменение состояния в зависимости от результата.
6. При выигрыше показать «Играть на выигрыш» или «Забрать и закончить».
7. Показать журнал событий и счётчик оплаченных раундов.
